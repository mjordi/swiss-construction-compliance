## Approved

### APPROVED — Make finalized linked protocols retrievable from Cases

**User-impact note:** The target user is a Swiss owner, contractor, project administrator, compliance lead, or adviser revisiting a case during notice preparation, escalation, or audit handoff. The workflow moment is after protocol finalization, when the one-time creation screen is gone but the legal record must remain usable. A real user will notice and benefit because expanded Cases details will expose each finalized source record and allow its factual PDF to be downloaded again. This is not incremental polish; it closes a material evidence-lifecycle gap.

**Explicit engineering task:** On branch `pipeline/2026-07-31-retrieve-finalized-protocols`, expand the existing linked-protocol read to include persisted report fields, add a pure record-to-report adapter that correctly interprets documented defects, the explicit no-visible-defects marker, missing statements, signature presence, case linkage, and finalization timestamp, then list finalized protocols in expanded case details with on-demand generation of the existing `AuditReportPDF`. Use deterministic filenames, localized UI feedback, stale/unmounted completion guards, and same-case pending lockout. Add focused adapter/UI and locale-parity coverage. Do not change Supabase persistence, schema, legal deadline math, checklist semantics, protocol finalization, routing, evidence upload, or existing CSV/ICS/dossier exports.

## Engineering result
