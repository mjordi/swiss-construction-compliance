## Approved

### APPROVED — Export one calendar for all active Case notice deadlines

**User-impact note:** The target user is a Swiss owner, contractor, project administrator, compliance lead, or adviser protecting deadlines across several active defect Cases. The workflow moment is after Cases exist and before fixed notice deadlines expire. A real user will notice because `/dashboard/deadlines` will show how many eligible active Case deadlines can be protected and download them in one portfolio `.ics`, replacing repetitive per-Case expansion/export. This is not incremental polish: it composes trusted legal Case intelligence into a new portfolio-level deadline-protection outcome while explicitly preserving the point-in-time/import-required/no-email-or-in-app boundary.

**Explicit engineering task:** On branch `pipeline/2026-08-14-case-deadline-portfolio`, add a pure portfolio selector and stable-UID multi-event ICS generator; load owner-scoped Cases on the authenticated deadlines page; exclude archived, malformed, future-discovery, old-law/no-fixed-deadline, and expired rows; deterministically order eligible events; render loading/error/empty/count states; use existing reminder presets and truthful activation guidance; guard stale user/request completions and duplicate exports; add DE/FR/IT/EN copy plus focused helper/UI/owner-switch/export tests. Do not change legal calculations, Case persistence/checklists, schema, active scheduling, providers, email/in-app notifications, or protocol behavior.

## Engineering result

Implemented on `pipeline/2026-08-14-case-deadline-portfolio`:

- Added a pure Case portfolio selector that reuses the established Case timeline/legal calculation contract and excludes archived, malformed, future-discovery, old-law/no-fixed-deadline, and expired Cases while retaining due-today deadlines.
- Added deterministic deadline/project/Case ordering and a localized multi-event RFC 5545 calendar generator with stable Case/deadline-derived UIDs, next-day all-day `DTEND`, normalized reminder alarms, control-character normalization, and UTF-8-aware 75-octet line folding.
- Added an owner-scoped portfolio section to the authenticated deadlines page with deterministic paginated loading, loading/error/empty/count states, source context, and one aggregate download using the page's current reminder presets.
- Added Swiss-midnight eligibility refresh and immediate pre-export revalidation so a page left open cannot export yesterday's expired deadline.
- Added request-generation, owner, unmount, Strict Mode, duplicate-export, blob/object-URL, timer, stale-completion, and retry safeguards; aggregate export never mutates a Case checklist or persistence state.
- Added DE/FR/IT/EN UI and calendar content that explicitly says the file is a point-in-time snapshot requiring calendar import and that BauCompliance sends no email or in-app reminders.
- Added focused selector/ICS, pagination, account-transition, midnight, Strict Mode, no-reminder, failure/retry, locale, and UI regression coverage.
