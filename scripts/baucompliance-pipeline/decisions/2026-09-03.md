## APPROVED — Export a finalized-protocol audit index

**User-impact note:** A Swiss construction owner, project administrator, contractor, or adviser preparing close-out, insurer/adviser review, a dispute, or an audit can export every successfully loaded finalized protocol as one source-identified CSV index instead of manually transcribing cards or opening each PDF. A real target user benefits at the evidence-handoff moment. This is not incremental polish: it adds the portable register layer between immutable source records and external portfolio review while preserving truthful point-in-time/no-retention/no-completeness boundaries.

**Explicit engineering task:**

1. Add a pure deterministic protocol-register CSV serializer and PII-safe date filename helper.
2. Include generation/scope metadata plus protocol ID, Case context, project, contractor, client, finalized timestamp, and localized signature state for every loaded finalized record.
3. Emit UTF-8 BOM and CRLF, standards-compliant escaping, and neutralize formula-capable spreadsheet cells including leading whitespace.
4. Add a Protocol Register export action only after a successful non-empty owner-scoped load; export all paginated records, independently of per-record PDF actions.
5. Add synchronous duplicate suppression, owner/request/unmount stale guards, object-URL cleanup, localized pending/success/error feedback, and timer cleanup.
6. Add focused helper, page, stale-lifecycle, DE/FR/IT/EN semantic, and locale-parity tests.

**Guardrails:** Read-only phase 1. Do not add queries, schema, mutations, evidence/defect contents, ZIP/PDF bundling, delivery/acceptance semantics, active monitoring, external retention, or claims of legal completeness.
