# Daily Product Improvement Proposals — 2026-08-12

## User and market lens

The primary user is a Swiss owner, contractor, project administrator, compliance lead, or adviser returning to BauCompliance to decide what needs attention now. The current dashboard opens directly on protocol creation even when existing Cases contain expired, immediate-notice, urgent, or warning states. That forces users to remember or navigate to the Case ledger before they can triage legal work. A best-in-market construction-compliance product should make the next consequential action obvious on entry, preserve the source Case context, and provide an audit-ready path into the established workflow without inventing new legal calculations.

## S — Show the count of actionable Cases in dashboard navigation

- **Target user and job-to-be-done:** Returning project team member who needs to know whether Case triage is waiting before opening another tool.
- **Problem:** Navigation gives no indication that urgent legal work exists.
- **Scope:** Reuse the existing owner Cases load to show an actionable count beside the Cases destination.
- **Expected impact:** Faster awareness, but little decision context.
- **User-visible outcome:** A count signals outstanding attention.
- **Competitive / best-product rationale:** Better than silent navigation, but weaker than showing what to do.
- **Risk:** 2/10.
- **Effort/size:** Small.

## M — Put a priority legal-action cockpit on the dashboard

- **Target user and job-to-be-done:** Returning owner, contractor, project administrator, compliance lead, or adviser who must triage deadlines and notices before starting new protocol work.
- **Problem:** The landing dashboard prioritizes protocol creation and hides the most urgent existing Case work one navigation step away.
- **Scope:** Reuse the existing owner-scoped Cases load and legal timeline model; rank up to three actionable Cases; show project, status, next action, and countdown before the step-1 wizard; link into existing filtered/searchable Cases views.
- **Expected impact:** Turns the dashboard from a single-workflow entry point into a bounded cross-workflow action cockpit.
- **User-visible outcome:** Users immediately see which Case needs action and can open the exact Case ledger context in one click.
- **Competitive / best-product rationale:** Best-in-market compliance software should prioritize legal work, not merely expose feature navigation.
- **Risk:** 3/10.
- **Effort/size:** Medium.
- **Phase-1 slice:** Read-only top-three cockpit using existing data and URL contracts; no new query, persistence, mutation, or legal calculation.

## L — Unified auditable work queue with assignments and completion evidence

- **Target user and job-to-be-done:** Multi-party construction teams coordinating every deadline, notice, evidence, protocol, and approval obligation.
- **Problem:** Existing workflows remain Case-centric and do not provide assigned ownership, due-state transitions, or one append-only cross-workflow queue.
- **Scope:** Persisted work items derived from legal events, assignments, acknowledgment/completion, immutable activity evidence, reminders, escalation, and tenant-safe team access.
- **Expected impact:** A complete operational compliance cockpit and defensible activity history.
- **User-visible outcome:** Every obligation has an owner, due state, action path, and recorded completion evidence.
- **Competitive / best-product rationale:** This is the step-change from tools and records to proactive compliance operations.
- **Risk:** 9/10.
- **Effort/size:** Large / strategic.
- **Phase-1 slice:** Define a tenant-isolated read-only derived work-item contract before introducing assignments or mutations.

## PM insights

Recent delivery has already built strong source records, evidence provenance, chronology, notice preparation, and truthful calendar handoffs, but the product landing surface still centers protocol creation. The last 14 days contain repeated bounded Medium and strategic phases rather than Small polish, with Cases/Vault and notice work heavily represented. Today’s strongest low-conflict step is therefore a dashboard composition layer: it makes existing legal intelligence actionable without touching open PR #188’s notice PDF implementation or adding another Case-detail refinement. A real target user will notice and benefit immediately because the first screen now answers “what needs legal attention next?”
